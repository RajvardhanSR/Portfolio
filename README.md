## ✦ Overview

A modern personal portfolio engineered with the visual language, storytelling polish, and cinematic micro-interactions of an Apple product launch. 

The site demonstrates end-to-end full-stack machine learning engineering — from exploratory data analysis and feature engineering to self-correcting agentic architectures, real-time microservices, and containerized cloud deployment.

### 🌟 Design Philosophy
- **Apple-Inspired Visual Language**: Minimalist dark palette (`#050507`), generous whitespace, crisp typography contrast, frosted glassmorphic navigation, and restrained electric sky blue / violet accents.
- **Interactive 3D WebGL Neural Scene**: Floating 3D neural synapse network built with Three.js that orbits and zooms dynamically on scroll, with smooth inertia-damped cursor parallax and a lightweight 2D canvas fallback.
- **Product-Style Case Studies**: Instead of static cards, each project is presented as an interactive engineering breakdown with dedicated full-screen 5-part deep-dive modals (*Problem, Approach, Architecture, Implementation, Results*).
- **100% Resume Fidelity**: All statistics, datasets, benchmarks, certifications, and experience are strictly drawn from verified credentials without fabricated claims.

## ⚡ Featured Engineering Systems

### 01. ClauseWise — Agentic RAG for Regulatory Compliance Q&A
> **Technologies:** `Python` • `OpenAI API` • `ChromaDB` • `Streamlit`

* **Self-Correcting Agentic Loop**: Built on top of standard retrieval with a sufficiency-check evaluator that detects incomplete context, invokes dynamic query reformulation, and caps retries to gracefully decline unanswerable queries rather than hallucinating.
* **Empirical RBI Benchmark**: Benchmarked against a single-pass baseline on real **Reserve Bank of India (RBI)** regulatory circulars (**242 chunks across 3 documents**), demonstrating clear advantages in multi-hop and cross-document dependency cases.
* **Interactive Evaluation**: Multi-page Streamlit demo comparing baseline vs. agentic answers side-by-side with groundedness scoring, hallucination flags, and an expandable trace of self-correction steps.

$$\text{USER QUERY} \longrightarrow \text{RETRIEVAL} \longrightarrow \text{SUFFICIENCY CHECK} \longrightarrow \text{QUERY REFORMULATION} \longrightarrow \text{RETRIEVAL (PASS 2)} \longrightarrow \text{GROUNDED ANSWER}$$

### 02. Customer Churn Prediction with Explainability
> **Technologies:** `Scikit-learn` • `FastAPI` • `Hugging Face Transformers (GPT-2)` • `AWS EC2` • `AWS S3` • `Docker`

* **Real-Time Prediction Service**: Scikit-learn classification model wrapped in a high-throughput, low-latency FastAPI microservice.
* **Natural Language Explanation**: Hugging Face GPT-2 layer translating raw probability scores into plain-language reasoning for non-technical stakeholders.
* **Production MLOps**: Model versioning, Pydantic schema validation, centralized AWS S3 model artifact storage, and containerized deployment on AWS EC2 via Docker.

$$\text{DATA} \longrightarrow \text{MODEL} \longrightarrow \text{API} \longrightarrow \text{EXPLANATION} \longrightarrow \text{AWS DEPLOYMENT}$$

---

### 03. Real-Time Network Traffic Anomaly Detection
> **Technologies:** `Python` • `Pandas` • `NumPy` • `Seaborn` • `Node.js` • `MySQL`

* **Streaming Telemetry Pipeline**: Watches streaming data in real time and flags unusual network traffic patterns as they happen, from raw telemetry to a MySQL analytics layer.
* **Statistical Thresholding**: Uses dynamic standard deviation thresholds over rolling windows to catch genuine spikes, significantly reducing false positives compared to naive rule-based alerting.
* **High-Throughput Optimization**: Tuned database indexing and processing pipelines to maintain low latency under continuous data streams.
